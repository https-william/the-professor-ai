# The Professor AI - Core UI Design System Code Constraints

## Typography Hierarchy
- Paragraph Body Baseline: font-sans text-[16px] antialiased text-slate-400
- Custom Core Heading Font: Use 'Urbanist' or 'Instrument Serif' from Google Fonts. Never default to 'Inter'.
- Heading Poland: All header blocks must compress tracking explicitly: tracking-tight leading-none font-bold text-slate-100.

## Layout Spacing & Paddings
- Every button, card container, or header grid padding alignment rule must explicitly align to an even, calculated 8-point block factor.
- Menu Selected States: Never use basic, thin borders. Indicate active tags via a smooth background elevation switch paired with a crisp neon-cyan marker node.

## Color Balancing Rules (Strict 60-30-10 Matrix)
- 60% Base Surface Canvas.
- 30% Structural Components: Elevated card containers (#0a0a0a / bg-zinc-950), line divisions, and deep muted text properties.
- 10% Intent Color. Use this exclusively for primary action highlights, correct answers, and active recall streak feedback pulses.

## Image & Icon Guidelines
- Eradicate all abstract illustrations or flat vector slop.
- Display clean, raw user interface cards showing actual document summary trees and active recall card decks.
- Icon Packs: Restrict all asset imports to 'Basil' or 'IcoMoon' structural sets.
